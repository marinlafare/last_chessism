Stockfish Lite for Chessism Live analysis

Upstream: https://github.com/nmrugg/stockfish.js
Release: https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1
Stockfish.js 19.0.1, lite single-threaded WebAssembly build, unmodified.

Provided without warranty. This engine is separate from Chessism's server engine.

The engine runs only after enabling Stockfish on the Live page. It uses one
browser worker, 16 MiB hash, up to 250,000 search nodes and three candidate lines.
It is stopped when disabled, interrupted by a newer position, hidden, or unmounted.
No browser evaluations are sent to the database or server analysis endpoint.
Only the .js and .wasm assets are needed during normal use (1,874,201 bytes total).

Source and rebuild materials, served from this same directory:
  stockfish.js-v19.0.1-source.tar.gz  (upstream source, build scripts and README)
  nn-61e7af4bb97d.nnue               (matching lite evaluation network)
  Copying.txt
  AUTHORS

To rebuild, extract the source archive, copy nn-61e7af4bb97d.nnue into its src/
directory, and follow its README's Emscripten setup instructions. Upstream pins
Emscripten 6.0.9. From the extracted root run:
  node build.js --lite --single-threaded --no-split
The source archive includes the engine modifications and compilation scripts.
The extra source/network downloads are optional and are not loaded by Live.
